===== FILE 2 : THREADING NOTES =====

Chapter 1: Threads in Java
----------------------------
A thread is the smallest unit of CPU execution.
Java supports multithreading natively via java.lang.Thread.
Threads share the same memory space within a process.

Chapter 2: Thread Lifecycle
-----------------------------
NEW       -> Thread created but not started.
RUNNABLE  -> Thread is ready or running.
BLOCKED   -> Waiting for a monitor lock.
WAITING   -> Waiting indefinitely for another thread.
TERMINATED-> Thread has finished execution.

Chapter 3: Synchronization
----------------------------
Race Condition  : Multiple threads access shared data unsafely.
Synchronized    : Keyword to lock a method or block.
Monitor Lock    : Every object has an intrinsic lock.
wait/notify     : Used for inter-thread communication.

===== FILE 1 : JAVA NOTES =====

Chapter 1: Introduction to Java
--------------------------------
Java is a high-level, class-based, object-oriented programming language.
It was designed to have as few implementation dependencies as possible.
Java applications are compiled to bytecode that runs on the JVM.

Chapter 2: OOP Concepts
------------------------
1. Encapsulation  - Wrapping data and methods together.
2. Inheritance    - One class acquires properties of another.
3. Polymorphism   - One interface, many implementations.
4. Abstraction    - Hiding internal details, showing functionality.

Chapter 3: Java Memory Model
-----------------------------
Stack Memory  : Stores local variables and method calls.
Heap Memory   : Stores objects and instance variables.
Method Area   : Stores class-level data and static variables.
