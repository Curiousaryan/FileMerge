# 📂 FileMerge

A lightweight Java application that merges the contents of multiple text files into a single output file. This project demonstrates Java file handling, stream operations, exception handling, and efficient file processing.

---

## 📌 Overview

FileMerge simplifies the process of combining multiple text files into one consolidated file while preserving the original content order. It is useful for log aggregation, document consolidation, and batch file processing.

---

## ✨ Features

- 📄 Merge multiple text files into a single file
- ⚡ Fast and efficient file processing
- 📝 Preserves file content order
- ❌ Handles invalid or missing files gracefully
- 💻 Simple command-line interface
- 📂 Supports customizable input and output file locations

## 🚀 Getting Started

### Prerequisites

- Java 17 or later
- Any Java IDE (IntelliJ IDEA, Eclipse, VS Code)

### Clone Repository

```bash
git clone https://github.com/Curiousaryan/FileMerge.git
```

### Navigate to Project

```bash
cd FileMerge
```

### Compile

```bash
javac Main.java
```

### Run

```bash
java Main
```

---

## 📖 How It Works

1. Select or specify the input files.
2. The application reads each file sequentially.
3. Contents are written into a single output file.
4. The merged file is generated in the specified output directory.
